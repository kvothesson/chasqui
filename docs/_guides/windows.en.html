chasqui is a free, open-source Windows app that translates speech as it happens. The app costs nothing: you pay OpenAI by the minute with your own API key. This page covers what to install and what to do when something does not work.

What each mode needs

Install it

  1. Download the installer (27 MB, Windows 10/11, 64-bit). It needs no Python and no admin rights.
  2. It is new and not code-signed yet, so you will see two warnings, which mean "Microsoft has not seen this file much", not "this file is harmful". In the browser, choose Keep. In "Windows protected your PC", choose More info, then Run anyway. The installer is built from the public source by GitHub Actions.
  3. Install VB-Audio Cable if your mode needs it.

With Python 3.11 or newer, you can use pip install chasqui-translate and then chasqui ui instead.

The first run

A setup window checks three things and tells you whether each is ready:

  1. Your OpenAI key. Paste it and press VERIFY. chasqui asks OpenAI whether the key can use the model.
  2. VB-Audio Cable. You get a link if it is missing.
  3. The device switcher, which moves your Windows audio devices for calls and videos. The installer brings it along.

DONE · TEST closes the window and runs a test translation. SETUP, under START, opens it again.

Turn on Stereo Mix for calls

A call needs a way to capture the other person's voice. If your sound card has Stereo Mix: open the Windows sound settings, go to the Recording tab, right-click and choose Show Disabled Devices, then enable Stereo Mix. Many PCs do not have it, and then the alternative is Hi-Fi Cable.

When something does not work

  • The light says ERROR: open DETAILS. The reason is in the log.
  • It picked the wrong device: open DETAILS, then AUDIO DEVICES, and pick by name. Press SEARCH AGAIN after plugging something in.
  • The other person hears nothing: lower the noise suppression in the call app.
  • Windows sound seems stuck on the cable: always stop with STOP or by closing the window, which hands your devices back. If the process was killed, set them back in the Windows sound settings.
  • Still stuck: open an issue with what the log says.

Mac and Linux

Not for audio yet: calls and video translation need Windows, because chasqui switches Windows audio devices for you. The text mode works on both with pip install chasqui-translate.
