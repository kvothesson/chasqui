chasqui es una app gratis y de código abierto para Windows que traduce la voz mientras habla la gente. La app no cuesta nada: le pagás a OpenAI por minuto con tu propia API key. Esta página explica qué instalar y qué hacer cuando algo no anda.

Instalalo

  1. Bajá el instalador (27 MB, Windows 10/11, 64 bits). No necesita Python ni permisos de administrador.
  2. Es nuevo y todavía no está firmado, así que vas a ver dos avisos, que quieren decir "Microsoft vio poco este archivo", no "este archivo es dañino". En el navegador, elegí Conservar. En "Windows protegió tu PC", elegí Más información y después Ejecutar de todas formas. El instalador se compila desde el código público con GitHub Actions.
  3. Instalá VB-Audio Cable si tu modo lo necesita.

Con Python 3.11 o más nuevo, también podés usar pip install chasqui-translate y después chasqui ui.

El primer arranque

Una ventana de configuración revisa tres cosas y te dice si cada una está lista:

  1. Tu key de OpenAI. Pegala y apretá VERIFY. chasqui le pregunta a OpenAI si la key puede usar el modelo.
  2. VB-Audio Cable. Si falta, te da el link.
  3. El cambiador de dispositivos, que mueve tus dispositivos de audio de Windows en los modos Headset y Media. El instalador ya lo trae.

DONE · PING cierra la ventana y corre una traducción de prueba. SETUP, debajo de START, la vuelve a abrir.

Activar Stereo Mix para las llamadas

El modo Headset necesita una forma de capturar la voz de la otra persona. Si tu placa de sonido tiene Stereo Mix: abrí la configuración de sonido de Windows, andá a la pestaña Grabación, hacé clic derecho, elegí Mostrar dispositivos deshabilitados y habilitá Stereo Mix. Muchas PC no lo tienen, y ahí la alternativa es Hi-Fi Cable.

Cuando algo no anda

  • La luz dice GLITCH: abrí BUFFER. El motivo está en el registro.
  • Eligió el dispositivo equivocado: abrí BUFFER, después AUDIO DEVICES, y elegilo por nombre. Apretá RESCAN después de enchufar algo.
  • La otra persona no escucha nada: bajá la supresión de ruido en la app de la llamada.
  • El sonido de Windows quedó en el cable: pará siempre con STOP o cerrando la ventana, que te devuelve los dispositivos. Si el proceso se cortó de golpe, volvelos a poner en la configuración de sonido de Windows.
  • Sigue sin andar: abrí un issue con lo que dice el registro.

Mac y Linux

Para audio todavía no: las llamadas y la traducción de videos necesitan Windows, porque chasqui cambia los dispositivos de audio de Windows por vos. El modo texto funciona en los dos con pip install chasqui-translate.
